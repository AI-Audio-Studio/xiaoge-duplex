## 产出 5:开工建议 —— **第一门通过(有边界),转第二门**

通过 = 全程放行"的误读:**

1. **可即刻推进(双门齐过后)**:PR-A1 / A2 / B —— agent 六处小改 + 池管理器 + 转码器。
   这些**不依赖目标机 N 定值**,按规划值 9~10 推进编码即可;每 PR 守"红→绿单测 +
   lint-ours + 行数门禁 + 87 存量全绿 + 逐 PR 评审"。
2. **须前置门禁方可跨越的两道坎(编码可并行、但不得先于其完成而"上线/对外承诺产能")**:
   - **目标机 N=8/10 摸底 + B5 资源复测**:这是设计头号风险(FunASR 18~20 流)的**门禁
     验证**,不是收尾动作(摸底报告 PB-4)。**产能 N 定值与上线前必须完成。**
   - **Q5 合规结论**:临时策略 D-20 可覆盖编码期,但**上线前**须有保留期/访问控制正式结论。

   PR-C(网关)/PR-D(集成+浸泡)可编码可测,但 **PR-D 的"上线"步骤 = 上述两坎的下游**,
   不得在两坎未过时执行。

**一句话结论**:设计与筹备已足以支撑**开始编码**(A1/A2/B 无保留);**上线产能**仍锁在
目标机摸底与合规两道前置门后——这与全程"零代码、双重门、开放存量不阻塞编码但阻塞上线"
的口径完全一致。
