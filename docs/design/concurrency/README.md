## 4. 维护规则（改文档时照此走）

1. **DESIGN 是唯一权威**。任何决策变更**先改 DESIGN 的 §2 决策总账**(加/改 D-xx 行,
   带溯源),再改相关正文;其他文件引用 DESIGN 的 §/D 编号,不复制其结论(防口径漂移)。
2. **ARCHIVE 只读**。已签署的评审往返原文不改;新评审往返追加到对应文件(PLAN/PROBE/
   KICKOFF)末尾,沿"评审意见 → 设计者应答"体例。
3. **溯源可查**。DESIGN §2 每条 D-xx 的"溯源"列 → ARCHIVE 附录编号;PROBE 的 PB-xx、
   PLAN 的 P-xx/W-xx 同理可回溯到评审原文。
4. **零代码红线**:双门齐过前不动任何工程文件;文档改动 commit 一律标"零代码"。
5. **开工顺序**:第二门批准后按 PLAN §10 起 PR-A1;目标机摸底/B5 复测/WP-0 可并行(待发令),
   但 **PR-D 上线步骤锁两门后**(见 KICKOFF 产出 5)。
